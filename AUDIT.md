# AUDIT.md : à compléter

Pour chaque ligne, retrouve le problème correspondant dans `src/App.tsx` / `src/App.css`
et remplis les 3 colonnes. Il y a **6 problèmes volontaires** dans ce starter.
 
| # | Problème trouvé (où, quoi) | Principe WCAG (P / O / U / R) | Pourquoi c'est bloquant, et pour qui |


| 1 | App.tsx(19) | P | Si tu est aveugle, ou que l'image ne marche pas --> Pas de description |
| 2 | Navigation Clavier | O | Pas de Navigation Clavier sur "voir" |
| 3 | "annulé"/"publié" | P | Pas info uniquement par la couleur|
| 4 | h1 suivi directement d'un h3 | R | Pas de h2 passe direct à h3 |
| 5 |  carousel pas fermable | O | le choix de fermer le carousel doit etre donné à l'utilisatur |
| 6 | "cliquez ici" | C | manque de description|

> Rappel : P = Perceptible, O = Opérable, U = Utilisable (Compréhensible), R = Robuste.
